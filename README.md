# TaskFlow

Простой и быстрый менеджер задач с прогресс-баром. Без бэкенда — данные хранятся локально в браузере (`localStorage`).

## Возможности

- ✅ Создание задач с приоритетом (низкий / средний / высокий)
- 📊 Прогресс-бар, который обновляется по мере выполнения задач
- 🔍 Фильтры: все / активные / выполненные
- 🗑️ Удаление задач и очистка выполненных
- 🌙 Светлая и тёмная тема (запоминается)
- 💾 Автосохранение в браузере + хранение данных в git

## Хранение данных в git

Источник правды — файл [`tasks.json`](tasks.json) в репозитории.

- При первом запуске (когда в браузере пусто) приложение **подтягивает `tasks.json`** из репозитория.
- Во время работы задачи кешируются в `localStorage` браузера.
- Кнопка **«⬇ Экспорт»** скачивает актуальный `tasks.json` — закоммитьте его в репозиторий, чтобы сохранить изменения в git.
- Кнопка **«⬆ Импорт»** загружает `tasks.json` из файла.

Типичный цикл: добавили/отметили задачи → «Экспорт» → положили скачанный `tasks.json` в корень репозитория → `git commit && git push`.

## Запуск локально

Это статичный сайт — никакой сборки не нужно. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```
